## 💡 Pro Tips

### GitHub
- Commit early and often (not just at end of day)
- Write clear commit messages
- Use @mentions for visibility
- Keep issues in sync with board
- Review others' code before merging

### Communication
- Ask in comments, not private messages
- Tag people who need to see it
- Include context (issue #, error message, etc.)
- Celebrate progress publicly
- Mark blockers immediately

### Development
- Test before committing
- Code to the interface (not implementation)
- Document as you go
- Help teammates who are stuck
- Keep local branch clean

### Presentation
- Prepare demo script
- Have backup demo (screenshot)
- Practice explaining your part
- Prepare for edge cases
- Be confident!
